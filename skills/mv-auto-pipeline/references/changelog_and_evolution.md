# 版本演进历史与工程规矩沉淀 (V1.0.0 ~ V1.0.6)

一支 MV 做过多少遍，就该有多少条规矩沉淀下来。
本 Skill 经过多支商业/个人全长 MV 的真实算力洗礼与血泪坑位验证，沉淀了以下规矩闭环：

## V1.0.0 · 首版奠基
- 确立「六大不可动摇铁律」体系。
- 引入「八道 HTML 审核关」与双关制（机审 + 人审）。
- 奠定「两道硬门禁」（关 5 提示词机检、关 6 窗口核对）不可绕过的安全基线。

## V1.0.1 · 假阳性与版本漂移修复
- 修正提示词机检中对中文歌词标点符号的正则误判。
- 解决多环境部署下 Python 与 Node 版本号微小漂移导致指纹不匹配的问题。

## V1.0.2 · 打掉五个毁灭全片的隐藏暗坑
1. **暗坑 1：单句歌词跨镜头切割** → 沉淀强制规则：分镜切点必须且仅能落在歌词句尾或乐句休止符。
2. **暗坑 2：远景走路莫名开口** → 沉淀硬约束：非中近景严禁标记口型，并在 Prompt 显式压制嘴唇动作。
3. **暗坑 3：累积时间漂移** → 提出自研「时长贴合（Duration Fitting）」算法，视频长度向上对齐帧网格并精准裁切。
4. **暗坑 4：上任用户人脸污染** → 强制执行共享工作流模板去参考化（清洗残留种子图与参考音）。
5. **暗坑 5：手写时间戳累积误差** → 彻底禁止任何手工秒数录入，时间轴全部自动化算术闭环。

## V1.0.3 · 补实文档承诺功能
- 补齐「无主角模式」：无需主人公图，智能以空镜、道具、背影、街景承载全片情绪。
- 补全双轨成片输出：一条原曲母带交付轨，一条逐段原音频盲审轨。

## V1.0.4 · 双池并行与真金白银封顶
- 引入双算力池策略（免费/低优先池 + 优先付费池）。
- 设立独立 Budget Cap 开关，杜绝未经授权扣款风险。

## V1.0.5 · 任务调度池退役策略优化
- 任务挂起退役逻辑由「重试错误次数」改为「实际等待时长 (Time-to-Live)」，规避偶发网络毛刺对健壮任务的误杀。

## V1.0.6 · 跨项目凭证自愈 (Current)
- 凭证四级寻址，全局用户配置生效，换新项目零配置冷启动，永久告别重复索要 API Key。
