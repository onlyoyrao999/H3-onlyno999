# MiniMax H3 格式·动作/语气/台词细化

版本：1.0.0｜整理自烨哥 2026-09-22 提供的 H3 官方文档与其实际案例格式

把分镜/剧情里的人物变化与台词，改写成 MiniMax H3 能生成音画同步视频的提示词：谁、在哪个镜头、什么语气、说什么、用什么动作带情绪，全部写进分镜脚本。

## 适用范围
- 仅服务 **MiniMax H3**（文本/图片生视频，原生音画同步：对话 + 音效 + 音乐同一次生成）。
- 不服务 Seedance、可灵等其他视频模型；目标模型不是 H3 时，一句话说明适用范围并立即停止，不提供替代模型或通用版。
- 适用：单/多镜头人物对话、对白反应、克制微表情；哭笑/失控/反转等强情绪时，按"情绪靠动作带"加大幅度即可，不另开扩展文件。

## 核心思路
- **台词是"时间线动作"的一部分**，写进分镜脚本，不单独拎出来描述。
- H3 原生音画同步，前提是提示词里把"谁 / 哪个镜头 / 什么语气 / 说什么"都交代清楚。
- **情绪靠动作带，不写形容词情绪**：别写"他很悲伤地说"，写"眼眶泛红、声音压低地说"——把情绪翻译成表情、语速、身体语言。
- **声音铁律：必须保留现场音效，严禁添加背景音乐 (Foley In, Score Out)**：
  - `【音效】` 项必须保留并细化描写（敲桌、搓烟纸、风噪、呼吸吞咽、环境底噪），赋予画面电影级拟音；
  - 严禁让 H3 生成背景配乐 (BGM/Score)，以防跨镜头切点断奏跳调，成片一律由后期外部挂载无损 Master BGM。

```text
subject_definitions（主体定义）:

<Subject 2> 是 <Picture 2> 中的男人：……
<Subject 3> 是 <Picture 3> 中的女人：……
<Subject 4> 是 <Picture 4> 作为起始画面参考图，控制开场构图、人物位置和场景状态。
声音设定：
<Picture 2> 是说话人用 (S2) 标记，参考音频 2，并在全片保持一致

【动作】……<Subject N> (SN) 动作与语气描述说：<d>[中文] 台词</d>
```

## 角色定义（subject_definitions）
- 每个角色/场景用 `<Subject N> 是 <Picture N> 中的<对象>` 定义；后面只引用标签，不重复外貌。
- **上传顺序固定**：`1=餐厅场景 / 2=男 / 3=女`；脸不像再加 `4/5` 特写。
- 餐厅场景(Subject1) 末尾写 "是餐厅场景，环境和空间结构参考"，并附**中文白名单**防漂移：
  "桌上物品以上述为准，全程不得添加、移动或碰触其他物件。"
- `<Subject 4>`（如有）作起始画面参考图，写"控制开场构图、人物位置和场景状态"。
- 参考图只锁身份/服装/环境指定部分，不自动继承参考图里的表情。

## 声音设定与音效边界
- 说话人用 `(S1)` `(S2)` 标记，并在全片保持一致。
- **两种声音输入模式（支持有/无参考音频）**：
  1. **有参考音频（音色克隆）**：注明参考音频编号并锁定声线：
     `例：<Subject1>，S1 永远是说话人。S1始终使用一种固定的声音：参考音频1（男.mp3），青年男性，中低音，音色温润清朗；常态语速中等、音量偏低。禁止播音腔。`
  2. **无参考音频（H3 原生自生成）**：若无外部音频，H3 自身的多模态声学网络会直接根据自然语言描述从零生成角色声线：
     `例：<Subject1>，S1 永远是说话人。S1始终使用一种固定的声音：约30岁成熟青年男性，中低音，沉稳霸道，声线磁性低沉；常态语速沉着有力、句尾自然收束。禁止夹子音、播音腔与夸张精英腔。`
- **音效全力保留**：在 `【音效】` 容器中详尽刻画现场物理声音（如：指节敲桌、搓烟纸、风声、衣服摩擦、呼吸吞咽、环境底噪），赋予画面电影级真实质感。
- **背景音乐彻底禁用**：
  - 严禁在提示词中索要背景配乐（BGM/Score），避免模型生成随机旋律导致切镜断奏；
  - 负向提示词全量封杀配乐：`background music, noisy score, discordant soundtrack, bgm, orchestral music, humming`；
  - 负向中**绝不添加** `sound effects` 或 `ambient`，放行所有现场物理拟音；
  - 全片由后期统一外挂无损 Master BGM 底轨。

## 分镜写法（detailed_description 容器内）
- 每个镜头：`【Shot N｜起止秒｜景别·描述】`，子项 `【主体】` / `【镜头】` / `【动作】` / `【音效】` / `【约束】`。
- **台词格式**：`<d>[中文] 原文</d>`，内嵌在 `【动作】` 里，前面带 `(起止秒)<Subject N> (SN) 动作与语气描述`。
- **语气写进动作**：音量/语速/情绪倾向随动作一起写（例："闷声从胸腔挤出，声音低沉发闷、像憋着气说"）。
- **情绪靠动作带**：用视线、呼吸、下颌、头肩、手与物件、声线等具体信号表达，不写"悲伤/压抑"等形容词。

## 防漂移（双保险）
1. **中文白名单**：在 Subject1 / Subject4 里写清"参照范围 + 全程不得添加、移动或碰触其他物件"。
2. **【约束】** 写一致性要求："五官稳定，面部不扭曲，口型与台词同步，画面无跳变；人物外观与服装前后一致，光线一致"。
3. 排除项合并成一组（同类合并，不超三组）："排除表情夸张、动作幅度过大、画面过亮或任何笑容轻松表情"。

## Agent 自动前置判断与声线自推演 (Autonomous Deduction)
- **输入感知与自决**：用户即使仅上传了 2 张人物图片或简短剧情梗概，Agent 必须在第 1 步全自动完成：
  1. **角色画像识别**：从图像中自动提炼人物年龄、性别、气质、服装辨识锚点与左右站位关系；
  2. **声音模式自决**：
     - 若提供了外部参考音频 ➔ 自动关联 `<Picture N>` 并绑定 `(SN)`；
     - 若**未提供参考音频** ➔ Agent 根据角色容貌与剧情性格，**自动编写完整的自然语言声线定义**（包括年龄段、中高/中低音域、音色特质、常态语速、情绪变化规律及禁用的发音风格如夹子音/播音腔等），使 H3 能 100% 凭文本自生成完美音色！

## 多模态空间逻辑与构图智能审图 (Composition & Spatial Auditing)
制作参考图、场景图、人物合成站位图及关键节点图时，Agent 必须执行严格的**「逻辑审图硬门禁」**：
1. **左右站位与 180° 轴线审图**：
   - 严格核验 `<Subject 1>`（左）与 `<Subject 2>`（右）的屏幕空间位置，严禁左右颠倒、越轴跳变或身份错位；
2. **物理立足与重力逻辑审图**：
   - 人物必须稳固立于地面或自然依坐在椅子上；严禁悬空、身体穿模、踩在桌子或不合逻辑的障碍物上；
3. **防走廊狭长陷阱审图**：
   - 室内/宴会/餐厅走道收窄至 1~1.5 张桌宽，两侧必须铺满陈设或宾客，严禁单侧排布形成空洞狭长走廊；
4. **脚底下边缘留空审图 (8.5% Margin)**：
   - 全身合成卡鞋底与画面下边缘必须保留约 8.5% 的地面空隙，严禁裁切脚踝或鞋底导致下坠感；
5. **道具交互与落版收束审图**：
   - 关键节点（如手持道具、依偎落版）必须审验持物手（左手/右手）、道具朝向（标签正面）、身体接触状态是否与落版参考图完全一致。

## 默认交付
普通请求只输出符合上方结构的完整提示词；不默认输出检查清单 / 审计 / 多版本。用户明确要求"解释 / 返修 / 对比"时再展开。

## 完整模板（已用"女人开口要校车费"场景验证，可直接套）
```text
subject_definitions（主体定义）:
<Subject 1> 是 <Picture 1> 中的餐厅：夜晚的家用餐厅，木桌居中、两侧各一把木餐椅；桌上方一盏暖黄吊灯；后窗深色窗帘半掩、窗外夜色暗；素色肌理墙、木地板。桌上有几盘没动过的饭菜（汤碗上结一层薄油）、两双木筷、一个圆形透明玻璃烟灰缸（里面已有几个烟头）。是餐厅场景，环境和空间结构参考；桌上物品以上述为准，全程不得添加、移动或碰触其他物件。
<Subject 2> 是 <Picture 2> 中的男人：约40岁，东亚面孔，深色短发略凌乱、面部有胡茬，深色旧短袖T恤、灰长裤、拖鞋；脸大半易陷吊灯阴影。
<Subject 3> 是 <Picture 3> 中的女人：约38岁，东亚面孔，黑长发扎马尾、两侧碎发，灰色长袖居家睡衣套装。
<Subject 4> 是 <Picture 4> 作为起始画面参考图，控制开场构图、人物位置和场景状态。
声音设定：
<Picture 2> 是说话人用 (S2) 标记，参考音频 2，并在全片保持一致
<Picture 3> 是说话人用 (S1) 标记，参考音频 1，并在全片保持一致
detailed_description:
【Shot 1｜0–4秒｜中景双人·女人开口】
【主体】<Subject 3> 画面左侧居主体，<Subject 2> 画面右侧虚化入镜。
【动作】<Subject 3> (S1) 视线落在桌上一盘凉透的青菜上，不看对面；右手指节轻敲桌面，前三下慢、后两下快，像在心里算账；说完停半秒，指尖停在桌面没抬起，尾音微微拖长、像例行公事却藏着试探，等他接话。音量中等、语速平稳、压着情绪说：
<d>[中文] 这个月小孩校车费，还有午餐费，你交一下</d>
【镜头】16:9 中景双人，餐桌侧面固定镜头，暖黄吊灯从上方打下、画面偏暗；左脸受光右脸暗。
【音效】暖吊灯底噪、冰箱嗡鸣；指节敲桌细微声响；无筷子声。
【约束】五官稳定，面部不扭曲，口型与台词同步，画面无跳变；人物外观与服装前后一致，暖黄偏暗光线一致。

【Shot 2｜4–7秒｜中景双人·男人回应】
【主体】<Subject 2> 画面右侧居主体，<Subject 3> 画面左侧边缘、视线仍落菜上。
【动作】<Subject 2> 先听见、没动，脸大部在吊灯阴影里，肩垮着缩在椅中；手指夹着没点的烟，指腹来回搓烟纸，发出细微沙沙声——没抬头、没接话。随后闷声从胸腔挤出，声音低沉发闷、像憋着气说：
<d>[中文] 我没钱</d>
说完嘴唇抿成一条线，喉结滚一下，把更多话咽回去；不再接话，烟仍在指间搓着，选了沉默不抬眼。
【镜头】16:9 中景双人，餐桌侧面固定镜头，与 Shot 1 机位一致。
【音效】搓烟纸细微沙沙声贯穿；说完后的换气与吞咽声；底噪贯穿；无对白外的言语。
【约束】五官稳定，面部不扭曲，口型与台词同步，画面无跳变；人物外观与服装前后一致，暖黄偏暗光线一致；排除表情夸张、动作幅度过大或任何笑容轻松表情。
```

## 旧约定说明
- 早期约定用过六字段（主体定义→任务概述→保留程度→分镜描述→环境音/人声→非剧情配乐）与英文标识符 `fully_preserved` / `[Static shot]`。
- 烨哥实际案例已改用中文白名单 + `【约束】`，**本 Skill 以中文白名单写法为准**，不强制输出 `fully_preserved` 等英文词；两者防漂移等效。
